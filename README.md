# 🚐 TravelTrucks

**TravelTrucks** — це вебзастосунок для компанії, яка спеціалізується на оренді кемперів.

Застосунок дозволяє користувачам переглядати доступні кемпери, фільтрувати транспорт за різними параметрами, переглядати детальну інформацію про кожен кемпер, ознайомлюватися з відгуками користувачів та оформлювати заявку на бронювання.

Проєкт створений з використанням сучасного стеку технологій **Next.js + TypeScript** із використанням компонентного підходу та оптимізованої роботи з API.

---

# 🚐 Каталог кемперів

Маршрут:

```
/catalog
```

На сторінці каталогу користувач може:

- переглядати список доступних кемперів;
- отримувати дані з backend API;
- фільтрувати кемпери за параметрами:

  - 📍 Location;
  - 🚐 тип кузова;
  - ⚙️ тип двигуна;
  - 🔄 тип трансмісії.

Особливості:

- фільтрація виконується через query-параметри backend API;
- реалізована пагінація у форматі **Load More**;
- при натисканні кнопки завантажуються додаткові картки;
- нові дані завантажуються з урахуванням активних фільтрів;
- використовується `useInfiniteQuery` з TanStack Query.

Кожна картка кемпера містить:

- основну інформацію;
- рейтинг;
- характеристики;
- кнопку **Show more**.

Кнопка **Show more** відкриває сторінку деталей кемпера у новій вкладці браузера.

---

# 🚐 Сторінка деталей кемпера

Маршрут:

```
/catalog/[camperId]
```

На сторінці відображається:

- повна інформація про кемпер;
- галерея фотографій;
- характеристики транспорту;
- відгуки користувачів;
- рейтинг у форматі ⭐⭐⭐⭐⭐;
- форма бронювання.

Додатково реалізовано:

- інтерактивну галерею зображень за допомогою Swiper;
- відправлення даних форми на backend;
- повідомлення про успішне бронювання;
- loader під час асинхронних запитів.

# ⚙️ Встановлення та запуск

## 1. Клонування репозиторію

```bash
git clone https://github.com/IhorKuzmenko/campers-next-js
```

## 2. Перехід у папку проєкту

```bash
cd campers-next-js
```

## 3. Встановлення залежностей

```bash
npm install
```

або

```bash
yarn install
```

---

## 4. Налаштування змінних середовища

Створіть файл:

```
.env.local
```

Додайте:

```env
NEXT_PUBLIC_API_URL=https://campers-api.goit.study
```

---

## 5. Запуск у режимі розробки

```bash
npm run dev
```

Проєкт буде доступний:

```
http://localhost:3000
```
